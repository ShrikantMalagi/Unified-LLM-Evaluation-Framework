# Changelog

## 0.1.0 - Unreleased

- Added the unified evaluation API for QA, RAG, chat, and code tasks.
- Added adapters for DeepEval, RAGAS, in-process/subprocess code evaluation, Docker-isolated code evaluation, and MLflow logging.
- Added strict output schema normalization and compatibility coverage for version-sensitive DeepEval/RAGAS behavior.
- Added packaging metadata, pinned direct dependency constraints, GitHub Actions CI, Ruff, mypy, package build validation, Twine metadata checks, and opt-in Docker/backend smoke workflows.

Release date is intentionally left as `Unreleased` until the first tagged release is cut.
